# もよう工房＆タングラム｜TT-sensei

図形を組み合わせて遊ぶ、小学生向けの図工ツール集です。自由に模様をつくる「もよう工房」と、お題の形にピースをはめる「タングラム」の2つが入っています。

公開サイト：https://tt-sensei.github.io/moyo-maker/
タングラム：https://tt-sensei.github.io/moyo-maker/tangram.html

## もよう工房（自由作り）

パターンブロック方式で図形を敷き詰めて模様をつくるツールです。2026-10-26に作り直しました。

- 敷き詰め図形は六角形・台形・正三角形・ひし形・正方形の5種で、全部の辺の長さが同じ。だから辺と辺がぴったり合って敷き詰められます（台形の長い辺は単位2つ分）
- 飾り図形（円・星・ハート）は自由に配置
- ドラッグ移動、30度ずつの回転（ボタン／ダブルタップ）
- 頂点吸着「ぴたっと」：ピース同士と背景のドット格子に吸着（オン／オフ切り替え可）
- 色の変更、複製、削除、ロック／解除、前後入れ替え
- 左右コピー、回転コピー（6方向）のアシスト
- 操作の取り消し・やり直し
- ドット格子の表示切り替え
- SVG形式で作品を保存
- 公式ナビキャラをヘッダーに小さく表示（作品のパーツとしては追加しない）
- 画面レイアウト：スマホは図形・編集パネルがスライド表示、タブレットは常時表示（縦向きは下に横並び、横向きは右に列表示）で画面を広く使う

## タングラム（お題パズル）

7つのピース（大きな三角2つ、中くらいの三角1つ、小さな三角2つ、正方形、平行四辺形）を動かして、お題のシルエットと同じ形をつくるパズルです。

- ドラッグで移動（画面の形に合わせて座標を正しく変換するので、横長の画面でも指に吸着するように動きます）
- 45度ずつの回転（ボタン／ダブルタップ）、平行四辺形などの裏返し
- 形が合ってくると頂点が「ぴたっ」と吸着
- 完成判定（シルエットの埋まり具合と、はみ出しをチェック）と「かんせい！」表示
- ヒント機能（次に置くピースの場所が光る）
- お題は19種類：自作の「おうち」「しかく」、自由作りの「じゆう」と、KiloGramデータセットから選んだ16種類（ねこ、いぬ、とり、さかな、ペンギン、ふくろう、きつね、うさぎ、うま、らくだ、きりん、はくちょう、へび、おはな、ちょうちょ、ロケット）
- 使わないピースは下の置き場に残したままで大丈夫です

### お題の出典について

お題の多くは、Cornell大学 LIL の [KiloGram Tangrams Dataset](https://github.com/lil-lab/kilogram) の形を使っています。形の名前は、同データセットに記録された「見た人の答え」の中で一番多かったものを日本語にしています。

KiloGramのデータとコードはMITライセンスです。ただしタングラムの図形そのものは、J. Slocum『The Tangram Book』（Sterling Publishing, 2003）をデジタル化したもので、Princeton大学図書館の通知に基づき教育・研究目的で利用が認められているものです。本サイトでは学校教育の目的で利用し、タングラムのページ内にも出典を表示しています。

## ファイル構成

- `index.html` / `app.js`：もよう工房（画面の構造・動作。見た目は index.html 内のスタイル）
- `tangram.html` / `tangram.js`：タングラム（画面と動作。見た目は tangram.html 内のスタイル）

見た目を調整するときは各HTML内のスタイル、機能を変更するときは `app.js`／`tangram.js` を編集します。

## 技術・運用

HTML / CSS / JavaScript / SVGのみで動作します。外部API、サーバー、ビルド手順、APIキーは不要です。作品データはサーバーへ送信しません。

GitHub Pagesで公開する場合は、リポジトリの Settings → Pages で、Deploy from a branch / main / root を選択してください。
