# もよう工房｜TT-sensei

図形を組み合わせて、自由に模様をつくる小学生向けの図工ツールです。

公開サイト：https://tt-sensei.github.io/moyo-maker/

## できること

- 正三角形、二等辺三角形、直角三角形、正方形、長方形、平行四辺形、ひし形、円、半円、六角形、星、ハートを配置
- 公式ナビキャラをヘッダーに小さく表示（作品のパーツとしては追加しない）
- 色の変更、ドラッグ移動、回転、大きさの変更
- 図形のロック／解除（誤操作防止）
- 30ピクセル単位で吸着する「ぴたっと配置」モード
- 正三角形・正方形・長方形・平行四辺形・六角形・ひし形などを辺がつながるように敷き詰める機能（形により配置方式は異なる）
- 描画ゾーンを広く保ち、図形・色パレットと編集ツールを左右からスライド表示
- 図形の複製・削除、重なり順の変更
- 円形コピー、横方向の複製、左右対称コピー
- 操作の取り消し・やり直し
- 方眼表示の切り替え
- SVG形式で作品を保存

## タングラムモード

`tangram.html` は、7つのピースでお題の形をつくるタングラムです。お題は「しかく」「おうち」「えんぴつ」と自由モード。ドラッグ移動、45度回転、裏返し、頂点への吸着、完成判定とヒントがあります。もよう工房のヘッダーから移動できます。

## ファイル構成

- `index.html`：画面の構造・操作ボタン
- `style.css`：色、配置、文字、スマートフォン対応などの見た目
- `app.js`：図形の追加・移動・編集、模様づくり、保存などの動作

見た目を調整するときは主に `style.css`、機能を変更するときは主に `app.js` を編集します。画面の部品やボタンを変えるときは `index.html` も確認してください。

## 技術・運用

HTML / CSS / JavaScript / SVGのみで動作します。外部API、サーバー、ビルド手順、APIキーは不要です。作品データはサーバーへ送信しません。

GitHub Pagesで公開する場合は、リポジトリの Settings → Pages で、Deploy from a branch / main / root を選択してください。
